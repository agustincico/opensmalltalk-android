## Full description (max 4000)

```
OpenSmalltalk brings a complete Smalltalk programming environment to Android — not a
viewer, not a remote session, but the real virtual machine running a real image on your
device.

Smalltalk is a live system. The code, the tools that edit it, and the objects it operates
on are all present at once, and all of them can be inspected and changed while they run.
That experience has been hard to reach on a phone. This app makes it a download away.

WHAT YOU CAN DO

• Pick an environment on first launch — Squeak, Cuis, or Cuis University — and it is
  downloaded for you. Nothing is bundled, so you get the version you want.
• Every image you open is kept on the device and reopens offline with one tap.
• Save your image and pick up exactly where you left off, with your objects intact.
• Bring code in: choose a .st fileout from your device and it is dropped straight into
  the running image, as drag-and-drop would on a desktop.
• Get code out: filing out from inside the environment puts the file in
  Downloads/OpenSmalltalk/ automatically, ready to share.

BUILT FOR FINGERS

A desktop Smalltalk expects three mouse buttons and a precise pointer. This app supplies
both. Two-finger tap or a dedicated button gives you the right-click menu; another opens
a morph's halos, which a touchscreen otherwise cannot reach. There is a trackpad mode
with a relative cursor and hover, a precise-pointer offset for small targets, and a zoom
picker with pixel-crisp whole-number scales. A soft-keyboard-aware view keeps what you
are typing above the keyboard.

HOW IT WORKS

The OpenSmalltalk virtual machine — the same one that runs Squeak and Cuis on the
desktop — is loaded in-process and renders through an X server embedded in the app. The
VM is built from pinned upstream sources with the Android NDK; the build recipe and the
portability fixes are public, and the fixes have been contributed back to the
OpenSmalltalk project.

OPEN SOURCE

MIT licensed. The full source, the VM build script, and the notices for every bundled
library are at:
https://github.com/agustincico/opensmalltalk-android

No ads. No analytics. No accounts. Nothing is collected, and nothing leaves your device
except the image download you ask for.

Requires an ARM64 device running Android 9 or later. Development is funded by FAST,
Fundación Argentina de Smalltalk.
```

## Data safety form — the answers

Every answer is "no", because the app collects nothing. The one that trips people up is
the first: *collected* means transmitted off the device, and this app transmits nothing.

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **No** |
| Is all of the user data collected by your app encrypted in transit? | n/a (no data collected) |
| Do you provide a way for users to request that their data is deleted? | n/a (no data collected) |

Data types — leave **every** category unticked: no location, no personal info, no
financial info, no health, no messages, no photos/videos, no audio, no files/docs, no
calendar, no contacts, no app activity, no web browsing, no app info/performance, no
device or other identifiers.

Note on the images the app downloads: those are files the *user* fetches to their own
device from public servers. They are not user data collected by the app, and nothing about
the user is sent with the request.
